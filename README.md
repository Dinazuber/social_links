# Ma page de liens : structure

```
linkpage3/
├── index.html
├── css/
│   └── style.css            ← couleurs et mise en page (:root)
├── js/
│   └── script.js            ← ton contenu (bloc CONFIG)
└── assets/
    ├── img/
    │   ├── avatar.png       ← ton avatar (à ajouter)
    │   └── background.gif   ← ton fond
    └── audio/
        └── ocarina.m4a      ← ta musique
```

Ouvre `index.html` dans ton navigateur. Pour GitHub Pages, envoie tout le dossier dans le repo et active Pages sur la branche `main`.
